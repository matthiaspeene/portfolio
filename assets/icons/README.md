# Capability icons

FMOD, Wwise, Unity, Unreal Engine, and JUCE SVGs are copied unchanged from [Simple Icons 15.0.0](https://github.com/simple-icons/simple-icons/tree/15.0.0/icons). The collection's CC0 license is included as `LICENSE.md`. Brand marks belong to their respective owners and identify tools used, without implying endorsement.

Original brand sources recorded by that release:

- [FMOD](https://www.fmod.com/attribution)
- [Wwise](https://www.audiokinetic.com/resources/credits/)
- [Unity](https://brand.unity.com)
- [Unreal Engine](https://www.unrealengine.com/en-US/branding)
- [JUCE](https://juce.com)

`sound.svg` and `music.svg` are simple project-authored capability symbols. C++ and C# use typographic badges. Every icon has a visible text label in the page.

The company logo is separate: the build copies `Assets/Images/NotJustSoundLogo.svg` from the vault without modifying it.
